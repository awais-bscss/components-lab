# Input

A styled text input component featuring label binding, left/right icon decoration, hint text, error states with live accessibility regions, and sizing variants.

## Import

```tsx
import { Input } from '@/components/primitives/Input'
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | `undefined` | Associated label text above the field |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Height and padding of the input |
| `error` | `string` | `undefined` | Error message displayed below input, triggering error styling |
| `hint` | `string` | `undefined` | Informational helper text below input (hidden when error is present) |
| `leftIcon` | `ReactNode` | `undefined` | Icon element placed inside the left edge of the input |
| `rightIcon` | `ReactNode` | `undefined` | Icon element placed inside the right edge of the input |
| `id` | `string` | auto-generated | ID attribute; automatically generated using `useId()` if omitted |
| `className` | `string` | `undefined` | Additional CSS classes merged onto input element |

All standard HTML `<input>` attributes (`value`, `defaultValue`, `onChange`, `placeholder`, `type`, `disabled`, `required`, etc.) are supported via `forwardRef`.

## Usage

### Basic with Label and Placeholder

```tsx
<Input
  label="Email address"
  placeholder="you@example.com"
  type="email"
/>
```

### With Helper Hint

```tsx
<Input
  label="Username"
  placeholder="john_doe"
  hint="Must be between 3 and 20 characters."
/>
```

### Error State

```tsx
<Input
  label="Email address"
  value="invalid"
  error="Please enter a valid email address."
/>
```

### With Icons

```tsx
import { SearchIcon } from '@/icons'

<Input
  placeholder="Search repository..."
  leftIcon={<SearchIcon className="w-4 h-4" />}
/>
```

## Accessibility

- The `<label>` element is automatically connected to the `<input>` via matching `htmlFor` and `id` generated by React 19's `useId()`.
- When an error is present:
  - `aria-invalid="true"` is set on the input.
  - The error element uses `role="alert"` so assistive technology announces it immediately.
  - `aria-describedby` links the input to the error element.
- When hint text is present without an error, `aria-describedby` links to the hint element (`role="status"`).
- Left and right decorative icons are marked `aria-hidden="true"`.
